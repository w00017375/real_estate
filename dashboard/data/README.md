# Географические границы

Файлы `tashkent_city_districts.geojson`, `tashkent_region_districts.geojson` и
`uzbekistan_regional.geojson`

[akbartus/GeoJSON-Uzbekistan](https://github.com/akbartus/GeoJSON-Uzbekistan).
Геометрия проекта подготовлена на основе данных OpenStreetMap. Условия лицензии
сохранены в `GEOJSON_LICENSE.txt`.
